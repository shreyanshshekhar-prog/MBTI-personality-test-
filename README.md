# TypeVision — 16 Personality MBTI Website

A modern, responsive, standalone web application for the Myers-Briggs Type Indicator (MBTI) personality assessment.

## ✨ Features

- **24 Calibrated Psychometric Questions**: Balanced across 4 cognitive dichotomies:
  - Energy: Extraversion (E) vs Introversion (I)
  - Information Gathering: Sensing (S) vs Intuition (N)
  - Decision Making: Thinking (T) vs Feeling (F)
  - Lifestyle Orientation: Judging (J) vs Perceiving (P)
- **Deep-Dive Profiles for All 16 Types**:
  - Analysts: INTJ, INTP, ENTJ, ENTP
  - Diplomats: INFJ, INFP, ENFJ, ENFP
  - Sentinels: ISTJ, ISFJ, ESTJ, ESFJ
  - Explorers: ISTP, ISFP, ESTP, ESFP
- **Interactive Report**:
  - Trait percentage breakdown dual-bars
  - Core superpowers & strengths
  - Psychological blindspots & growth tips
  - Ideal career paths & work culture matches
  - Relationship dynamics & romantic compatibility
  - Famous historical and fictional figures
  - Jungian cognitive function stack (Dominant, Auxiliary, Tertiary, Inferior)
- **Zero-Dependency & Fast**: Runs entirely client-side. No npm or node builds required.
- **Dark & Light Mode**: Auto-detects system theme with one-click manual toggle.
- **Auto-Save & Keyboard Shortcuts**: Progress is saved to `localStorage`. Use keys `1-5` and arrow keys to navigate questions.
- **Share & Print**: Copy shareable links or print clean PDF reports.

## 🚀 How to Run

### Method 1: One-Click Python Server (Recommended)
From this directory, run:
```bash
python3 server.py
```
This automatically launches your web browser to `http://localhost:8000`.

### Method 2: Open Directly
Double-click `index.html` or open it in any web browser (`Chrome`, `Safari`, `Firefox`, `Edge`).
